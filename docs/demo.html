1 · Text fonts (regular Unicode Arabic)

These render normal Arabic text. Use them when you have Unicode strings — any Qur'an text or Arabic prose.

General Arabic (not Qur'an-specific)

Uthman Naskh is a general Arabic text face from the KFGQPC — use it for any Arabic prose, not only Qur'an.

/* Uthman Naskh (regular + bold) */
@font-face {
  font-family: 'Uthman Naskh';
  src: local('KFGQPC Uthman Taha Naskh'),
       url('../other-fonts/fonts/UthmanTN1%20Ver10.woff2') format('woff2');
}
@font-face {
  font-family: 'Uthman Naskh';
  font-weight: bold;
  src: local('KFGQPC Uthman Taha Naskh Bold'), local('KFGQPCUthmanTahaNaskh-Bold'),
       url('../other-fonts/fonts/UthmanTN1B%20Ver10.woff2') format('woff2');
}

2 · Icon / symbol fonts

Each codepoint draws a single figure — not a composable letter. QPC Symbols is general mushaf annotation marks (sajdah, waqf, etc.) — not tied to any riwaya. QCF_BSML is the basmalah ligature set used alongside the v1/v1.5 Hafs page fonts.

/* Mushaf annotation marks (sajdah, waqf, rub el hizb, end-of-ayah, etc.) */
@font-face {
  font-family: 'QPC Symbols';
  src: local('KFGQPC Arabic Symbols 01'),
       url('../other-fonts/fonts/Symbols1_Ver02.woff2') format('woff2');
}

/* Basmalah set (primary ligature U+FB51..U+FB56 plus many alternates) */
@font-face {
  font-family: 'QPC Basmalah';
  src: local('QCF_BSML'),
       url('../hafs-glyphs/v1/fonts/QCF_BSML.woff2') format('woff2');
}

3 · Page-based glyph fonts

These fonts do not render Unicode Arabic. Each glyph is a pre-shaped word pinned to a specific mushaf page. You can only render mushaf content you have the matching glyph data for — see hafs-glyphs/README.md and warsh-glyphs/README.md for the data files and format.
Load one font per page. For v1 / v1.5 / v2, every page has its own font file — don't preload all 604. Declare them lazily as the user navigates, or declare the single page you need. All samples below use page 42 (Ayat al-Kursi) as the example.

QPC v1 — one font per page

/* Basmalah (shared — not per page) */
@font-face {
  font-family: 'QCF_BSML';
  src: url('../hafs-glyphs/v1/fonts/QCF_BSML.woff2') format('woff2');
}

/* One @font-face per page. Replace NNN with the 3-digit page number (001–604). */
@font-face {
  font-family: 'QCF_P042';
  src: url('../hafs-glyphs/v1/fonts/QCF_P042.woff2') format('woff2');
}
/* …QCF_P001 through QCF_P604 available at the same path pattern. */

QPC v1.5 — one font per page (same codepoint scheme as v1)

@font-face {
  font-family: 'page_42';
  src: url('../hafs-glyphs/v1.5/fonts/page_42.ttf') format('truetype');
}
/* Files: page_1.ttf … page_604.ttf */

QPC v2 — one font per page, pages 1–100 only in this repo

@font-face {
  font-family: 'QCF2042';
  src: url('../hafs-glyphs/v2/fonts/QCF2042.ttf') format('truetype');
}
/* Files: QCF2001.ttf … QCF2100.ttf (pages 1–100).
   Pages 101–604 have no font in this repo; use v1/v1.5 or v4 for those. */

QPC v4 Hafs — ~13 pages per font

/* v4 fonts cover page ranges, not single pages. The correct font for each
   word is the `p` field in hafs-glyphs/v4/data/quran.json. */
@font-face {
  font-family: 'QCF4_Hafs_04_W';
  src: url('../hafs-glyphs/v4/fonts/QCF4_Hafs_04_W.ttf') format('truetype');
}
/* Files: QCF4_Hafs_01_W.ttf … QCF4_Hafs_47_W.ttf */

Rendering page-glyph text in the browser

Two things you need beyond the @font-face:

/* 1. PUA codepoints default to LTR in Unicode bidi — force RTL so
      wrapped lines stay in reading order: */
.mushaf-page {
  direction: rtl;
  unicode-bidi: bidi-override;
  word-break: break-all;      /* allow wrap between any two glyphs */
}

/* 2. Set font-family to the page/font corresponding to the glyphs you're rendering: */
.mushaf-page.p42 { font-family: 'QCF_P042'; }   /* v1 */
.mushaf-page.p42-v15 { font-family: 'page_42'; }   /* v1.5 */
.mushaf-page.p42-v2 { font-family: 'QCF2042'; }   /* v2 */
<!-- v1: look up line `42,...` in hafs-glyphs/v1/data/mushaf.txt,
     paste its glyphs, set the page font: -->
<div class="mushaf-page p42">ﮣﮤﮥﮦﮧﮨﮩﮪﮫﮬﮭﮮ...</div>

For v4, iterate hafs-glyphs/v4/data/quran.json[s-1][v-1] and emit each word with its own font-family QCF4_Hafs_{p:02d}_W.
