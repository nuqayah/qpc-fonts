Page-glyph fonts

These fonts render one word per glyph, pinned to a specific mushaf page. They require the matching data/mushaf.txt to produce readable text. The samples below show QCF_BSML (basmalah) and page 1 of v1 as a visual check only.

Mushaf v1 · Basmalah hafs-glyphs/v1/fonts/QCF_BSML.*
ﱁﱂﱃﱄ
Mushaf v1 · Page 1 hafs-glyphs/v1/fonts/QCF_P001.*
ﭑﭒﭓﭔ
@font-face 
@font-face {
  font-family: 'Mushaf Page NNN';
  src: local('QCF_PNNN'),
       url('https://raw.githubusercontent.com/nuqayah/qpc-fonts/master/hafs-glyphs/v1/fonts/QCF_PNNN.woff2') format('woff2');
}
